研思智护 · 项目 B 开发源码包
=================================================

本包包含两套产品，共用同一套服务端与数据库：

  研思智境       http://127.0.0.1:8787/          教师入口 /login，管理员入口 /admin/login
  舞镜智练/舞安智护 http://127.0.0.1:8790/wuan   姿态识别舞蹈教学辅助（独立启动）

--------------------------------------------------
一、先自检（推荐）
--------------------------------------------------
  npm run doctor

逐项检查运行环境、目录权限、许可文件、姿态资产与测试套件，
给出「可以交付 / 需要处理」的明确结论。只读、不联网。

--------------------------------------------------
二、研思智境（主产品）
--------------------------------------------------
  npm run init-admin -- --login <登录名>   按提示设置管理员密码（不内置任何默认密码）
  npm start                                默认 http://127.0.0.1:8787/

  环境变量见 .env.example。正式部署务必设置 YANZHI_MASTER_KEY 并妥善保管，
  否则数据目录丢失后已保存的模型 API Key 无法解密。

--------------------------------------------------
三、舞镜智练 / 舞安智护
--------------------------------------------------
  npm run setup:pose     获取 MediaPipe 姿态资产（需联网；已存在则跳过）
                         内网/离线环境请从其它机器拷贝 public/vendor/mediapipe/ 后
                         运行 npm run verify:pose 校验
  npm run init:dance     初始化
  npm run start:dance    启动，默认 http://127.0.0.1:8790/wuan

  说明：真实多模态（视频理解）供应商尚未接入。未配置供应商时，
  姿态分析按设计降级为纯几何指标，不生成任何未经验证的结论。

--------------------------------------------------
四、测试与验收
--------------------------------------------------
  npm test               90 项，全部通过，约 110 秒，不需要联网

当前结果与浏览器走查结论见 VERIFICATION.md —— 这是本包唯一的测试结论出处，
其它文档中的测试数量可能已过时。
