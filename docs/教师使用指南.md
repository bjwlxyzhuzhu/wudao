# 研思智境 · 教师使用指南（10 分钟上手）

“研—演—评—改”多智能体数字教研实验工坊

**模块命名**：平台的两个核心模块采用两层命名。首页、顶部导航和两个模块之间的流转使用简称，进入页面后显示正式名称。
- **研课场**：数字教研室 · 多智能体协同研课
- **演课场**：课堂试验场 · 多智能体课堂预演

> 第一次演示或上手，建议直接看图文版《演示操作手册》：平台顶栏点 📖 操作手册（地址 `/manual`）。

## 数字客服思思
屏幕右下角水晶球里的“思思”是平台的数字客服：
- 点她就可以提问，例如“怎么把课件送到演课场上课”；回答会注明来自哪份说明文档。
- 点 🔊 开关语音朗读，每条回答旁的“▶ 朗读”可以单独朗读。
- 登录后与平台共享管理员配置的大模型，不扣积分；登录前或没有模型时，用本地知识库回答。
- 她的知识库与训练过程在“智能体 → 客服数字人 · 思思”。

## 1. 登录
打开 `http://127.0.0.1:8787/`，用管理员给你的账号和临时密码登录，首次登录需要修改密码。开放自助注册时，可以在登录页注册，并从 12 个 3D 水晶球头像中选择一个；之后可以在“账号、积分与备份”中更换。退出登录时可以选择“退出并清空缓存”（清除本机的偏好、指引记录和与思思的对话，不影响服务器上的成果）。新账号有 100 积分；只有“大模型生成”会消耗积分，本地生成、编辑、流转、导出都不扣分。每个页面第一次打开时会有浮动指引，之后可以点顶栏的“? 指引”重新查看。

**字号**：顶栏右上角的三个“A”分别是标准、较大、特大字号，选择会被记住。

**显示模式**：顶栏右上角可选“自动 / 浅色 / 深色”。“自动”跟随电脑或手机的系统设置；选择会保存在当前浏览器中，下次打开仍然有效。登录页右上角也可以切换。

## 2. 研课场：导入课程内容，系统自动完成后续任务
1. 进入“研课场”，点“新建任务”。
2. **导入课程内容**：上传讲义、大纲、课件、习题（DOCX / PPTX / XLSX / TXT），或点“或粘贴文字”直接粘贴讲义。系统会自动识别课程名称、专业、学时、单元和知识点（有明确定义的会标出），这些信息都可以修改。请不要上传含学生个人信息的文件；手机号、身份证号、学号、邮箱会自动隐去。
3. **选择要重点研讨的知识点**（默认前 4 个，最多 8 个），教研组会逐个讨论：讲解要点、难点与易错点、思政怎么融入、检测题。
4. **要生成的成果**：勾选单课教案、课件、模拟练习、模拟试卷、大纲、课程教学设计、学期教学设计、教学计划进度表、人才培养方案等，选定一个“主成果”，再选择课时（15 / 25 / 45 / 50 / 90 分钟）。默认会用主成果模拟上课，并按课堂反馈修订主成果。
5. **执行**：窗口底部会列出将依次执行的步骤。“本地生成”依据导入内容抽取和组织，不调用大模型，不扣积分；“大模型生成”需管理员配置模型，开始前会显示最多消耗的积分。
6. 任务在服务器上自动执行。右上“❚❚ 暂停任务 / ▶ 继续任务”随时暂停和继续；已完成的步骤和成果都会保留，关闭页面或重启服务后也能继续。右侧“任务进度”标签页列出每一步的结果。
7. 研讨中可以点右下“参与研课”，就课程知识本身提问（例如“系统误差和随机误差有什么区别？”），教研组会依据导入的材料回答，并注明出自哪个文件。
8. 任务完成后，所有成果都在产物库中，其中包括“知识点与思政融入图谱”。需要自定义研讨模式或席位时，可在新建任务的“高级设置”中进入“自定义单次研讨”。

### 研课场页面怎么看
- **左上：多智能体研讨区**
  - 八位教师的发言按时间排列，“↩ 回应 某某”表示在回应谁。
  - 标签“课程思政”“证据待补充”“来源已核查”标出关键点，上方可以按类别筛选。
  - 在下方输入框可以直接发言；点“＠教师”（或点下方圆桌上的教师头像）可以指定由谁回应。
- **右上：研讨任务进度**
  - 显示真实的“已完成步数/总步数”和当前环节。
  - “研讨成果”页实时呈现教学目标（知识、能力、育人）和思政要点。
- **下方：数字教研圆桌**
  - 红色表示正在发言，“思考中”表示下一位发言者，金色提示表示发现证据缺口或有待回应的质询。
  - 鼠标移到教师上，可以看到他的职责和最近一次发言。

## 3. 首页箭头：把产物送进课堂
回到首页，点击 **→**，确认后当前产物（例如教案）就会导入演课场。课堂结束后生成的“课堂反馈”可以用 **←** 带回研课场，作为修订依据。

## 4. 演课场：按课时上一节课
1. 进入“演课场”，点“新建课堂”，选择**上课时长**（例如 50 分钟）、班级规模、互动自由度等，再选择**运行倍速**：1× 是真实课堂节奏，2×—60× 会更快。
2. 大屏上方是上课计时和各环节进度，“讲解内容（跟学）”中老师正在讲的段落会高亮，你可以像学生一样跟着学。倍速可以随时切换。
3. 学生会自主、随机地提问、质疑和讨论；点右下“参与课堂”可以用教师或学生身份插话，以学生身份提问时老师会优先回应。
4. 下课（或点“结束”）后点“生成课堂反馈”：其中有未解决的问题、各环节计划用时与模拟用时的对比、讲解完成度和修订建议。

### 演课场页面怎么看
- 默认 40 名学生智能体，分成 8 组 × 5 人；顶部“班级 40人”旁可以改成 5 组 × 8 人、10 组 × 4 人或自定义，下一次开课生效。
- 左上“课堂实况”只显示最重要的事件，包括正在发言的学生、最近的教师引导和最近几条互动；“查看完整记录”可展开全部。
- 右上“课堂实时数据”的 6 项指标都来自本节课的模拟事件，“小组活跃度”按各组发言次数计算。
- 下方每组只显示一位代表和其余成员的状态点：红色发言、橙色举手、蓝色小组讨论、金色思考、空心未发言。点小组可以看到 5 名成员的状态、发言次数和最近观点，也可以直接点名。
- 教师调控：“随机点名”优先选尚未发言的学生；“指定小组发言”让该组派代表发言；“发起全班讨论”向全班提问。被点名的学生或小组代表会在下一步回应。
- 下课后点“生成课堂反馈”，再点“返回研课场继续改进”，反馈就会送回研课场，由教研团队据此修订教案。

### 播放器条（两个页面相同）
- 页面顶部的播放器条从左到右依次是：回退、开始/继续、暂停、快进、结束（课堂中为“下课”），中间是进度条。
- 拖动进度条到已经发生的部分，或点“回退”，可以回看当时的发言和小组状态。回看不会改变课堂或研讨，点“回到实时”即可继续。
- 拖到还没发生的位置，或点“快进”，系统会连续推进到那里后停住。使用大模型时，快进会按次扣积分，开始前会提示。
- 课堂的倍速（1×—60×）在播放器条右侧。

## 智能体中心（顶栏“智能体”）
- **教师智能体**：
  - 8 位固定教师的姓名与职责不变，可以“更换形象”（上传图片）或“恢复默认形象”。
  - 2 位自定义教师可以从模板（专业课教师、专业博导、企业工程师、教学督导）开始，填写名称、姓名、职责和专属提示词；启用后，在研课场“席位设置”中勾选即可入席。
- **导入数据训练**：
  1. 阅读并勾选 8 条数据采集原则。
  2. 选择教案、讲稿、说课稿、评课记录等资料。
  3. 系统依次执行采集校验、文本抽取、隐私脱敏、质量清洗、切分入库、特征提取、人设画像、检索验证，可以看到每一步的结果。
  4. 完成后，这位教师在研讨中会引用你的资料，并带上你的表达习惯。资料可以随时撤回。
  - 这不是修改大模型本身，而是把你的资料作为这位教师的“记忆”和风格参考。
- **学生智能体**：
  - 导入匿名的班级画像表（先下载模板）。姓名、学号列会被丢弃。
  - 系统按先修水平异质分组，并把每一行分配给一名学生智能体。
  - 点“用于开课”后，演课场会按这份画像开课。
  - 学生形象可以单个或批量上传，文件名写座位号（S01）或学生姓名。
- **研课八步**：研课场按“任务分配 → 讨论交流 → 写作初稿 → 对抗质询 → 打磨修改 → 整合汇总 → 集体评审 → 形成终稿”顺序执行。会议室下方的进程条显示每一步的进度、用时和预计完成时间；“进程记录”页签有详细记录。

## 科研数据中心（顶栏“科研”）

1. **新建研究项目**：填写研究问题、研究设计、组别（如 `EXP=实验组`）、时间点（如 `T0=前测`）、伦理批准号、AI 使用声明。右侧“发表前自检”会提示还缺什么。
2. **被试与知情同意**：
   - 点“导入名册”，选择 Excel 或 CSV。表头可以用自己的叫法，系统会自动对应。
   - 姓名、学号等列会被忽略。
   - 只有“已同意”的被试进入分析与导出。
   - 被试退出时把状态改为“已退出”，需要时可点“删除其数据”。
3. **量表与测试**：
   - 新建量表或测试；也可以从结构模板开始（需粘贴原题），或从产物库的试卷生成。
   - 导入题项后再导入作答：一行是一名被试在一个时间点的作答。
   - 点“计算”查看信度（α）或题目分析。
4. **话语编码**：
   - 导入课堂或教研转录，建立编码表并导入代码。
   - 每位编码者填写自己的假名，逐条点代码。编码时看不到别人的结果。
   - 完成后点“计算编码者一致性”和“滞后序列分析”。
5. **评分一致性**：多位评价者在“人工评分”页勾选“盲评模式”独立评分，或导入线下评分表，然后在这里查看 κ、α、ICC。
6. **数据包导出**：一次下载项目全部数据，附 SPSS 语法、R 脚本和数据字典；也可以单表导出 Excel、CSV、SPSS 或 JSON。

## 产物库

- 默认按“课程 → 层级”分组，每条版本线只显示最新版，点“历史版本”可查看以前的版本。
- 可以改为按层级、模块、状态、来源分组，也可以搜索和筛选。
- 编辑器里每张表格都有“导入表格 / 导出表格”：导入的内容先填入编辑区，检查无误后再点“保存草稿”。

## 5. 编辑、导出与评分
- **产物库**：可以编辑产物，保存为正式版本；右侧“结构校验”和“课程思政融入自检”会提示学时或分值是否对得上、融入点是否口号化、价值目标是否被评价。
- 大纲、教案、试卷等可以导出 DOCX；试卷分学生卷和教师答案卷。
- **人工评分**：按七维量规对发言逐条评分，“未评、不适用、证据不足”都不记为 0。
- **数据导出**：先预览再下载研究数据包，默认已做假名化，不含自由文本。

## 研课场的学情依据

- 新建研讨时可以在“学情依据（班级画像）”中选择已导入的班级画像。
- 选择后，“学情分析”会写入该班的先修水平分布、常见误解等统计。
- 不选择时，学情分析会注明“尚未导入班级画像”，不会编造学情。

## 常见问题
- **PDF 能上传吗？** 暂不支持，请先另存为 DOCX。
- **“真实模型”选不了？** 需要管理员在后台配置模型和 API Key，默认预填 DeepSeek。
- **课堂里的时间是真实时间吗？** 不是。这是演课场时钟，按发言字数和动作估算，只用于教学演练，不代表学生的真实学习时长。

## 运行方式：模拟演示 / DeepSeek API 运行
- 研课场和演课场页面顶部都有“运行方式”按钮，新建任务、新建课堂的窗口里也有同样的两张卡片：
  - **🎬 模拟演示**：依据导入的课程内容本地生成，不调用大模型，不扣积分。
  - **⚡ DeepSeek API 运行**：由大模型实时生成发言，按成功调用扣积分。开始前会显示最多消耗的积分。
- 从研课场导入教案后，进入演课场直接点“▶ 开始上课”即可开课，使用默认设置和当前选中的运行方式。想调整班级规模、课时等参数时，点“新建课堂”。
- 如果大模型调用失败（例如管理员配置的模型 ID 有误），页面会说明原因，失败的调用不扣积分。这时可以点“改用模拟演示开课”继续。
