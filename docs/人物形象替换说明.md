# 人物形象替换说明

平台中所有人物（8 位固定教师、2 位自定义教师、全部学生智能体，以及真人教师用户）都以 **3D 水晶圆球头像** 呈现：
- 球内是本地渲染的仿真人物形象（纯 SVG，参数固定，不随刷新变化，外观与能力、性格无关）；
- 教师为暖金玫瑰色玻璃球，学生为冰晶蓝玻璃球，真人为青色玻璃球并标“真人”；
- 球体有影棚底光、边缘折射、顶部高光、底部聚光和双层轮廓光。

**不需要上传任何照片。** 平台不含图像生成模型，无法生成照片级的“真人”面孔；球内形象是渲染出来的仿真人物，不是照片。以下上传说明仅在你确实希望替换时使用，上传的图片也会自动放进水晶球。

## 通用要求

- **来源**：只使用你用图像生成工具生成的虚构人物，或已获本人书面授权的照片。不要使用网络上的真实人物照片。
- **构图**：正面或微侧的半身像，头顶到胸口，人物居中，头部约占画面上半部。
- **尺寸**：正方形，建议 512×512 以上。上传时系统会自动裁成正方形并压缩：教师 256px，学生 192px。
- **风格统一**：同一批形象使用同一种风格（如“半写实 3D 渲染、柔和影棚光、浅暖色背景”），避免照片与卡通混用。
- **格式**：PNG、JPEG 或 WebP。

## 学生智能体

前 40 名学生有固定姓名：第 1—40 位依次为赵子涵、钱浩宇、孙雨桐、李俊杰……云浩然，完整列表见“智能体中心 → 学生智能体”。默认每 5 人一组。

- **单个上传**：在“学生智能体”页点击某位学生即可上传。
- **批量上传**：点“批量上传学生形象”，一次选择多张图片。文件名写成座位号（如 `S01.jpg`、`S12.png`）或学生姓名（如 `赵子涵.png`），系统会自动对应。
- 建议统一描述为“大学生、20 岁左右、半写实 3D 渲染、校园休闲装”，并让性别与固定姓名一致（姓名列表中已区分）。
