# 舞镜智练与舞安智护账号密码及操作手册

本手册用于比赛演示和本地验收。公开演示密码仅适用于隔离的演示环境，不能直接用于公网正式部署。

## 1. 访问入口

服务默认地址为 `http://服务器地址:8787`。

| 功能 | 地址 |
| --- | --- |
| 舞镜智练 | `/wujing` |
| 舞安智护 | `/wuan` |
| 管理员后台 | `/admin/login` |

## 2. 演示账号

| 身份 | 账号 | 密码 | 所属班级 | 使用入口 |
| --- | --- | --- | --- | --- |
| 管理员 | `admin01`、`admin02` | `Admin123` | 全局管理 | `/admin/login` |
| 舞蹈教师 | `teacher01`、`teacher02` | `Teach123` | `dance-a` | `/wujing` |
| 舞蹈教师 | `teacher03` | `Teach123` | `dance-b` | `/wujing` |
| 学生 | `student01`—`student03` | `Student123` | `dance-a` | `/wujing`、`/wuan` |
| 学生 | `student04`—`student06` | `Student123` | `dance-b` | `/wujing`、`/wuan` |
| 风险复核教师 | `medic01` | `Medic123` | `dance-a` | `/wuan` |

班级数据相互隔离。舞蹈教师只能查看本班训练记录；风险复核教师只能查看授权的健康与负荷记录；学生只能查看本人数据。

## 3. 快速启动

### 使用源码启动

```powershell
npm run setup:pose
npm run init:dance
npm run start:dance
```

### 使用容器启动

```powershell
docker compose up --build -d
```

默认容器配置会开启演示账号。正式部署前必须关闭演示模式，并通过服务器 Secret 设置独立密码。

## 4. 管理员操作

1. 打开 `/admin/login`，使用管理员账号登录。
2. 在模型管理中查看千问配置状态、模型 ID 和 API Key 末四位。
3. 需要轮换密钥时，在服务端更新 `DASHSCOPE_API_KEY` 后重启；不要把密钥写进网页、源码或 GitHub。
4. 正式环境应设置 `YANZHI_SECURE_COOKIE=1`，并通过 HTTPS 访问。
5. 账号停用、角色调整或密码重置后，相关旧会话会失效。

## 5. 舞蹈教师操作

1. 打开 `/wujing` 并登录教师账号。
2. 进入“动作标准”，从一位站姿、二位站姿、二位 plié 蹲、Tendu 擦地、Passé 静态吸腿、Dégagé 小踢腿中选择动作。
3. 填写拍摄视角、教学要求、安全边界和可观察检查点，然后发布标准。
4. 学生提交后，在“训练复核”打开记录，查看姿态指标、千问辅助草稿和证据。
5. 教师独立采纳、修改或否决 AI 建议，填写优点、优先改进项和下一轮练习后发布。

AI 结果不会直接成为学生正式评价，必须经过教师复核。

## 6. 学生操作

1. 打开 `/wujing` 并登录学生账号。
2. 选择已由教师发布标准的动作，上传 3—30 秒、20 MB 以内的单人练习视频。
3. 根据需要分别勾选教学分析、云端关键帧分析和服务器保存原片授权。
4. 等待本机骨骼点和角度提取。质量不足、多人入镜或视角不匹配时按提示重拍。
5. 教师发布反馈后，在“成长记录”查看结果并按同一标准再次练习。
6. 需要撤回时删除本次授权及分析数据。

## 7. 健康与疼痛记录

1. 学生打开 `/wuan`，填写疲劳、睡眠、疼痛程度、疼痛部位、训练分钟数和 RPE。
2. 健康数据需要独立授权，不与普通舞蹈教师共享明细。
3. `medic01` 在 `/wuan` 查看本班授权记录并进行人工复核。
4. 当前功能用于状态记录和健康教育，不提供医学诊断，也不自动给出绿色安全结论。

## 8. 千问配置

运行实例需要设置：

```dotenv
DASHSCOPE_API_KEY=在千问控制台新建的密钥
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_VISION_MODEL=qwen3-vl-plus
```

曾经出现在聊天、截图、日志或公开文件中的密钥必须先在千问控制台撤销，再生成新密钥。GitHub 仓库和容器镜像只保留变量名，不保存真实值。

## 9. 正式部署账号

正式公网部署时设置：

```dotenv
DANCE_DEMO_MODE=0
DANCE_BOOTSTRAP_ACCOUNTS=1
DANCE_ADMIN_PASSWORD=独立强密码
DANCE_TEACHER_PASSWORD=独立强密码
DANCE_STUDENT_PASSWORD=独立强密码
DANCE_MEDIC_PASSWORD=独立强密码
YANZHI_MASTER_KEY=64位十六进制随机值
YANZHI_SECURE_COOKIE=1
```

首次启动后会创建固定登录名，后续重启不会覆盖已有密码。建议首次登录后立即在后台为不同使用者设置独立账号，不要长期共用一组密码。

## 10. 常见问题

- 登录失败：确认入口与身份匹配；管理员必须从 `/admin/login` 登录。
- 看不到学生记录：确认教师和学生属于同一班级。
- 没有 AI 结果：检查 `DASHSCOPE_API_KEY`、API Host、模型 ID、云端分析授权和关键帧质量。
- 浏览器不回传 Cookie：HTTPS 环境设置 `YANZHI_SECURE_COOKIE=1`；本地 HTTP 调试保持为 `0`。
- 更新镜像后数据为空：确认仍挂载原 `wudao-data` 数据卷，并保持 `YANZHI_MASTER_KEY` 不变。
