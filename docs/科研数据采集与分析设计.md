# 科研数据采集与分析设计（面向教育学、教育技术学、思想政治教育类 CSSCI / SSCI 论文）

> 本文说明平台能帮你**采集、整理、导出**哪些研究数据，以及能计算哪些量规、测试和一致性指标。
>
> - 平台**不生成、不补齐任何研究数据**。
> - 期刊的具体要求以目标期刊的投稿须知为准；本文只列常见的审稿关注点。

## 1. 数据从哪里来

| 数据 | 性质 | 在平台的位置 | 导出文件 |
|---|---|---|---|
| 研课场、演课场的运行过程（事件、阶段、调度、时间） | **平台过程数据**，含智能体模拟 | 自动记录 | 顶栏“数据导出”：runs、events、scheduler_decisions、metrics…；或项目包 `platform/` |
| 教学产物及其版本 | 教师与 AI 协作形成的文本 | 产物库 | artifacts、artifact_sections |
| 人工评分（按量规） | 真实评价者的判断 | 人工评分（可开盲评）/ 导入外部评分 | ratings；项目包中的一致性结果 |
| 被试名册与知情同意 | **真实研究数据** | 科研 → 被试与知情同意 | participants.csv |
| 问卷量表作答 | 真实研究数据 | 科研 → 量表与测试 | responses_long / responses_wide_*.csv + .sps |
| 测验作答 | 真实研究数据 | 科研 → 量表与测试（可从产物库试卷生成） | 同上 |
| 课堂 / 教研转录与编码 | 真实研究数据（导入的转录）；也可引入平台模拟对话，但会单独标注 | 科研 → 话语编码 | units、codings、ena_*、lag_sequential_*、irr_* |

**关键边界：**

- 演课场的“学生”是智能体，不是样本。
- 用模拟数据只能回答关于平台或模拟本身的问题，例如“多智能体研课是否促使教师修改了价值目标”，不能回答“学生是否学会了”。

## 2. 可支持的研究设计（示例）

| 设计 | 研究问题示例 | 需要采集 | 平台内分析 | 导出后分析 |
|---|---|---|---|---|
| 准实验（前后测 + 对照组） | 平台研课是否提升教师课程思政教学设计能力？ | 教师名册（组别）、设计能力量表 T0/T1、教案产物、盲评量规分 | 量表 α、各组×时间点描述统计、评分者一致性 | 协方差分析 / 混合方差分析、效应量 |
| 设计型研究（DBR，多轮） | 研课八步流程如何迭代才能减少“贴标签”式融入？ | 每轮运行过程、产物版本、自检结果、教师访谈转录 | 编码与一致性、各轮产物版本对比 | 质性主题分析、轮次比较 |
| 课堂话语分析 | 真实课堂中价值问题的师生互动模式是什么？ | 课堂转录、编码表（如 IRF、价值表达类型） | κ / α、滞后序列（调整残差） | ENA（导出 ENA 格式）、序列模式分析 |
| 学生层面调查 + 测验 | 课程思政学习体验与知识掌握的关系 | 学生名册、自编或改编量表、单元测验 | α、题目分析（难度、区分度、KR-20） | CFA、结构方程模型、回归 |
| 混合方法 | 上述量化结果如何被访谈解释？ | 量表 + 访谈转录 | 两部分各自的信度与一致性 | 联合展示（joint display） |

## 3. 量规、测试与评价

- **量规（评分标准）**
  - 内置“教学互动与反思过程量规草案 v1”，可导入自定义量规 JSON（每个等级都要有锚点描述）。
  - 评分支持“未评 / 不适用 / 证据不足”，这三种都不按 0 分计。
  - 重评保留修订链。
- **盲评**：人工评分页勾选“盲评模式”后：
  - 隐藏发言者身份、生成方式和他人评分；
  - 事件顺序按评价者编码打乱。
  - 评价者一律用假名编码（R01、R02…）。
- **评分者一致性**：每个量规维度计算加权 κ（2 人）、Krippendorff α（有序）、ICC(2,1)。建议先共同校准 10% 左右的样本，再独立评分。
- **量表**：
  - 支持李克特等级、反向题（计分：最小 + 最大 − 原值）和维度。
  - 自动计算各维度、各时间点的 Cronbach α、校正题总相关、删题后 α，以及各组 × 时间点的维度均分描述统计。
- **测试**：
  - 题型：单选、多选（顺序无关）、判断（对/√/T 等价）、填空（可设多个可接受答案）、主观题（填得分）。
  - 自动计分后做题目分析：难度 P、区分度 D（27% 高低分组）、校正题总相关、KR-20 或 α。
  - 可以直接从产物库的“模拟试卷”生成测试，题目与课程目标关联。
- **结构模板（不含原题）**：
  - 已知量表：TPACK、TAM、NASA-TLX、SUS。只给出维度结构与题数，题项为“占位”。请粘贴原量表题项并注明来源与授权。
  - “课程思政教学能力”和“学生课程思政学习体验”目前没有公认的成熟量表，只提供自编维度建议，需做专家评议、预测试与 EFA/CFA。
  - 占位题项在自检和导出中都会标出。

平台采用的阈值惯例：

- κ：Landis & Koch (1977)；
- Krippendorff α：≥ .800 可靠，.667—.800 可作暂定结论；
- ICC：Koo & Li (2016)；
- α：常用 .70 门槛。

这些只是参考，请按目标期刊的要求报告。

## 4. 所有表格数据的智能导入 / 导出

| 数据表 | 导入 | 导出格式 |
|---|---|---|
| 被试名册 | ✓ | XLSX / CSV / SPSS / JSON |
| 量表题项、测试题目与答案键 | ✓ | 同上 |
| 作答数据（宽表：一行一人一时间点） | ✓ | 同上；项目包另含长表 |
| 编码表（代码、定义、纳入/排除规则、示例） | ✓ | 同上 |
| 话语单元（课堂 / 教研转录） | ✓ | 同上 |
| 编码结果 | ✓ | 同上 |
| 人工评分（外部评价者） | ✓ | 同上 |
| 产物中的每一张表格（教学目标、教学过程、试题…） | ✓（填入编辑区，确认后保存） | XLSX / CSV / SPSS / JSON |
| 班级画像（智能体中心） | ✓（原有导入流程） | — |

**智能导入流程：**

1. 选文件：支持 .xlsx、.csv、.tsv、.json，可选工作表和表头所在行。
2. 表头自动对应到字段：
   - 先按同义词匹配（如“编号 / 代号 / ID”都对应被试编码）；
   - 再按相似度匹配；
   - 每列标出匹配把握（精确 / 高 / 请核对），可以手动改。
3. 逐行校验：类型、取值范围、选项、日期（含 Excel 日期序列号）、组别和时间点是否存在、被试是否已登记。问题行逐条列出。
4. 选择“按编码更新并新增”或“只新增”；有问题的行可以选择跳过。

**隐私：** 姓名、学号、身份证号、手机号、邮箱等列自动忽略，预览中也不显示其值；话语文本中的手机号、身份证号会被自动隐去。

**导出：**

- XLSX：中文表头，另附“字段说明”工作表。
- CSV：字段键作表头，UTF-8 带 BOM，并做公式注入防护。
- SPSS：CSV 加 `.sps` 语法，含变量标签、值标签和测量尺度。
- JSON：含字段定义。
- 导入模板：只有表头和字段说明，**不含示例数据**。

## 5. 伦理与数据治理

- 项目中填写伦理委员会、批准号、批准日期、知情同意书版本；没有批准号时写豁免理由。
- 被试只用研究编码，不录入姓名和学号。
- 知情同意状态决定数据能否进入分析：
  - 只有“已同意”的被试进入分析和导出；
  - 拒绝、待确认、已退出者的数据不导出；
  - 未登记编码的作答在导入时即被拒绝，不会被悄悄纳入。
- 被试退出后，可一键删除其全部作答、转录和编码；名册保留“已退出”记录，用于报告被试流程。
- 数据包内容：
  - README：研究问题、设计、组别、时间点、伦理信息、被试流程、AI 使用声明、数据可得性声明；
  - 数据字典；
  - R 读取脚本；
  - SHA-256 清单。
- 话语正文默认不进数据包，需要时勾选“包含话语正文”。共享前请确认已去标识化。
