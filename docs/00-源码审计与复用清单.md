## 技术基线

- Node.js ≥22.13，ES Modules；HTTP、SQLite、密码学等使用 Node 内置模块。
- 前端为原生 HTML、CSS 和 JS 模块；无 React/Vite 构建。
- SQLite 为当前数据库；不是 PostgreSQL。
- 包清单无第三方运行依赖，无需为现有功能运行 `npm install`。
- 未找到仓库内 AGENTS.md 或 LICENSE 文件。
- `upstream` 指向原公开 GitHub 仓库；未建立自有 `origin`。

## 本地运行

在当前开发目录运行 Node ≥22.13：

```powershell
node server/cli.js create-admin --login admin
node server/server.js
```

以上为保留的上游启动方式：首条命令交互设置管理员密码。默认本机地址 `http://127.0.0.1:8787/`；管理入口 `/admin/login`。新舞蹈界面使用 `npm run init:dance`、`npm run start:dance`，端口 8790，详见 `../README-DANCE.md`。未配置模型时仅使用真实姿态指标，不冒充 AI 结论。

没有系统 Node 时，可使用：`C:/Users/21494/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`。
