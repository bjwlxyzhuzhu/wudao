# 权限矩阵、接口与字段契约、安全脱敏检查

## 1. 角色与会话

- 教师会话 Cookie `yz_t`（scope=teacher），管理员会话 Cookie `yz_a`（scope=admin），两者独立。HttpOnly、SameSite=Strict，可选 Secure。
- 服务端每个接口按 scope 校验：教师接口要求 `is_teacher` 且会话 scope=teacher；后台接口要求 `is_admin` 且 scope=admin。**前端页面路由不承担权限控制**。
- 资源所有权：产物、运行、事件、评分、流转、备份均按 `owner_id = 当前会话用户` 过滤；请求体中的 `user_id`/role 不被采信。访问他人资源一律返回 404（不泄露是否存在）。
- 非 GET 请求要求 `x-yz-csrf: 1` 头，且 Origin 必须同源。
- 首次登录（`must_change_password`）除改密码/查看本人/退出外全部拒绝。
- 登录限流：同一登录名或 IP 15 分钟内失败 5 次即拒绝。禁用账号立即注销全部会话，并停止其进行中的运行、释放未用预占。

## 3. 运行状态机

`ready → running ↔ paused`；`running → awaiting_human`（真人打开输入浮层）`→ running`；终态 `completed / cancelled / failed`。积分预占与运行关联但独立（`reservations` 表），可对账；长时间未活动的运行自动暂停并释放预占，服务重启时进行中的运行转为暂停、在途调用标记失败且不扣分。

## 4. 积分账本契约

- 状态：`available = total_balance − reserved_balance`；数据库 CHECK 约束保证 total≥0、reserved≥0、reserved≤total。
- 流水类型：`initial_grant`（键 `initial:<user>`）、`admin_grant/admin_deduct`（键 `admin:<batch>:<user>`）、`reserve`、`settle`（键 `settle:<call>`）、`release`、`reversal`（键 `reversal:<entry>`）。
- 调用前在预占内占用额度（`inflight`），成功且持久化后在同一事务中写事件、结算并记录调用；失败只归还额度。重试关联 `retry_of`。

## 5. 主要字段

完整字段口径见研究导出包中的 `data-dictionary.md`（由 `server/research.js` 生成）。关键点：

- `events`：`sequence/elapsed_ms/inter_event_ms/reply_to/reply_latency_ms/composer_opened_at/submitted_at/input_dwell_ms/source/model_call_id/decision_id`。
- `scheduler_decisions`：`trigger/n_candidates/n_eligible/speak_probability/draw/hands/selected_agent/action/target/group/cooldown/top_weights/distribution_version/seed`。
- `model_calls`：`request_at/first_token_at/completed_at/latency_ms/input_tokens/output_tokens/request_id/model_id/key_version/status/error_code/credits/retry_of`。仅记录真实返回值，未知为空。
- `artifacts`：`lineage_id/version/parent_id/status(draft|saved)/origin/framework_key/template_version/source_run_id`；段落含 `author/revision/last_event_id`。
- `transfers`：`source_artifact_id/source_version/target_artifact_id/source_run_id/evidence_event_ids/saved_draft_first/idempotency_key/confirmed_by`。
