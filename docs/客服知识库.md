# 研思智境 · 数字客服“思思”知识库

> 数字客服思思依据本知识库以及平台的全部说明文档（README、教师使用指南、演示操作手册、科研数据采集与分析设计、人物形象替换说明、评审与改进记录）回答问题。资料里没有的内容，她会如实说明“资料中没有”，不会编造功能。

## 思思是谁

思思是研思智境的数字客服老师，也是平台里的一位智能体，出现在屏幕右下角的水晶球里。
- 平台的功能和业务流程她都学习过：她的知识库来自平台全部说明文档，可以在“智能体中心 → 客服数字人”查看训练过程并重新训练。
- 点她就可以提问，回答可以语音朗读。
- 她与平台共享管理员配置的大模型：有模型时用大模型组织回答，没有模型时直接从知识库里找答案。
- 向她提问不扣积分。

## 平台是什么

研思智境是一个“研—演—评—改”多智能体数字教研实验工坊，包含两个核心模块：
- **研课场（数字教研室）**：8 位教师智能体协同研课，把讲义变成大纲、教案、课件、练习、试卷等成果；
- **演课场（课堂试验场）**：40 名学生智能体（默认 8 组 × 5 人）模拟上课，生成课堂反馈。

课堂反馈带回研课场后，教研组会据此修订成果，形成“研—演—评—改”闭环。

## 登录与注册

- 在登录页输入管理员开通的登录名和密码。管理员创建的账号第一次登录必须先修改密码。
- 如果登录页有“注册教师账号”，可以自助注册：
  - 填写登录名（3—40 位字母、数字或 _.@-）、显示名和密码（至少 8 位，含字母和数字）；
  - 从 12 个 3D 水晶球头像中选一个。
- 没有“注册”入口，说明管理员没有开放自助注册，请联系管理员开通账号。
- 忘记密码请联系管理员重置，平台不会通过客服查询或发送密码。

## 头像

- 注册时可以从 12 个头像中选择；之后可以在右上角“账号、积分与备份”页的“我的头像”中随时更换。
- 头像都是 3D 水晶圆球里的卡通人物，不需要上传照片。

## 退出登录与清空缓存

点右上角用户名 → 退出登录，会弹出两个选项：
- **退出登录**：只结束登录，本机的界面偏好（主题、字号、倍速、简洁视图、指引记录等）保留；
- **退出并清空缓存**：结束登录，同时清除本浏览器中平台保存的偏好、指引记录、临时草稿和与思思的对话记录。

两种方式都不会删除服务器上的教案、课件、研究数据等任何成果。公用电脑建议选“退出并清空缓存”。

## 运行方式与积分

研课场和演课场顶部都有运行方式开关：
- **模拟演示（本地生成）**：不调用大模型，不扣积分，几秒出结果，适合演示和练习；
- **DeepSeek API 运行（大模型）**：需要管理员先配置模型和 API Key，按成功的调用次数扣积分，开始前会显示最多消耗的积分。

积分说明：
- 新教师账号一次性获得初始积分（默认 100），由管理员分配，平台没有充值；
- 查看、编辑、流转、导出和本地生成都不扣积分；
- 点顶栏的积分可以查看积分流水；
- 向思思提问不扣积分，但每人每小时有次数上限，超过后改用本地知识库回答。

## 一门课的完整流程（推荐演示路线）

1. **研课场**：点“新建任务”，导入讲义（DOCX / PPTX / XLSX / TXT，或粘贴文字），系统自动识别课程和知识点。
2. 勾选要生成的成果（如思政版教学大纲、课程思政课件），选择主成果和课时，可选择班级（学情依据），点“开始执行”。
3. 任务自动完成：解析 → 知识点研讨 → 知识点图谱 → 其余成果。成果保存在产物库。
4. **产物库**：打开课件，点“送到演课场上课 →”。
5. **演课场**：点 ▶ 开始上课（默认 10× 倍速）；下课后点“生成课堂反馈”。
6. 在反馈弹窗中点“返回研课场继续改进 →”：反馈自动带回研课场，教研组依据反馈修订原课件；修订完成后点“确认为当前产物”。
7. 修订后的课件可以再次送到演课场上课。

详细图文步骤见顶栏 📖“操作手册”（地址 /manual）。

## 研课场

- **新建任务**：
  - 导入课程内容后，选择要重点研讨的知识点（默认前 4 个，最多 8 个）、要生成的成果、主成果、课时（15 / 25 / 45 / 50 / 90 分钟）和班级（学情依据）。
  - 主成果为教案、课件、练习或试卷时，可以勾选“用主成果模拟上课，生成课堂反馈，并据此修订主成果”。
- **研课八步**：任务分配 → 讨论交流 → 写作初稿 → 对抗质询 → 打磨修改 → 整合汇总 → 集体评审 → 形成终稿。
- **8 位教师智能体**：
  - 陈立诚（教研组长）、林知远（教学设计教师）、苏婉清（专业教师）、许嘉宁（思政教师）；
  - 周衡远（评价专家）、郑守真（证据审查教师）、高振宇（行业导师）、李一诺（青年教师）；
  - 另有 2 位可以自定义的教师。
- **参与研讨**：在输入框发言，点“＠教师”可以指定由谁回应；可以就课程知识提问，教研组会依据导入的材料回答并注明出处。
- **播放器条**：回退、开始/继续、暂停、快进、结束，以及进度条；拖动到已经发生的部分可以回看。
- **简洁视图**：页面顶部点“简洁视图”，只保留研讨对话、任务进度和播放器；再点“完整视图”恢复。
- **席位设置**：勾选参加研讨的教师，至少 3 位，组长固定主持。
- **没有可以修订的反馈时**：研课场顶部不会出现修订横幅。反馈带回后，会显示“依据这份反馈修订原产物 →”。

## 演课场

- **开课**：
  - 当前产物来自研课场的“送到演课场上课”或首页的 → 箭头。
  - 点 ▶ 开始上课；“新建课堂”可以调整课时、班级规模、互动自由度、倍速等。
- **班级**：
  - 顶部“班级”下拉框可以选择分组方式（如 8 组 × 5 人），或选择导入的班级画像。
  - 选择画像后，人数、分组和每名学生的先修水平、发言活跃度、质疑倾向、常见误解都来自画像。
- **倍速**：默认 10×，可以选择 1×（真实节奏）、2×、5×、10×、20×、60×。
- **教师调控**：“随机点名”优先选尚未发言的学生；“指定小组发言”让该组派代表发言；“发起全班讨论”向全班提问。
- **参与课堂**：可以用教师或学生身份插话，以学生身份提问时老师会优先回应。
- **课堂反馈**：下课后点“生成课堂反馈”，内容包括：
  - 未解决的问题；
  - 各环节计划用时与模拟用时的对比；
  - 讲解完成度；
  - 修订建议；
  - 思政相关发言的“说理式 / 口号式”统计（启发式，需人工复核）。
- **标签说明**：
  - 顶部“课件 · 研课场 v3”表示当前上课用的是研课场第 3 版课件；
  - 版本号在两个场之间连续编号，旧版本不会被覆盖。

## 产物库

- 默认按“课程 → 层级”分组。层级依次为专业层、课程层、课堂层、练习与评价、反馈与反思、知识图谱。
- 也可以按层级、模块、状态、来源分组，并支持搜索、筛选和排序。
- 每条版本线默认只显示最新版，点“历史版本”查看以前的版本。
- 打开产物后可以：
  - 编辑内容，点“保存草稿”；
  - 保存为正式版本（表示教师已审阅）；
  - 设为当前产物；
  - 送到演课场上课；
  - 导出 HTML、DOCX 或 JSON。
- 每张表格都有“导入表格 / 导出表格”：可以在 Excel 中编辑后导回，导入的内容会先填入编辑区，确认后再保存。
- 右侧有结构校验、课程思政融入自检（融入偏少或过度、表述雷同、与专业内容脱节）、目标—活动—评价一致性。

## 智能体中心（顶栏“智能体”）

- **教师智能体**：
  - 8 位固定教师可以“导入数据训练”：阅读并确认 8 条数据采集原则 → 选择教案、说课稿等资料 → 8 个阶段依次完成（采集校验、文本抽取、隐私脱敏、质量清洗、切分入库、特征提取、人设画像、检索验证）。
  - 训练后，这位教师在研讨中会引用你的资料、带上你的表达风格。这是知识与风格注入，不是修改大模型本身；资料可以随时撤回。
- **自定义教师**：可以设置名称、姓名、职责和专属提示词，有专业课教师、专业博导、企业工程师、教学督导四个模板；设置后在研课场“席位设置”中勾选即可入席。
- **学生智能体**：
  - 导入匿名的班级画像表（先下载模板），姓名、学号列会被自动丢弃；
  - 系统按先修水平异质分组，把每一行分配给一名学生智能体；
  - 点“用于开课”后，演课场会按这份画像开课。
- **客服数字人**：思思的知识库、训练过程和检索验证结果都在这个页签，可以点“重新训练”。
- **形象**：所有人物都以 3D 水晶圆球呈现，教师为暖金玻璃，学生为冰晶蓝玻璃，不需要上传照片。

## 评价与科研（顶栏“评价与科研”）

- **人工评分**：
  - 按量规给事件评分，可以标记“不适用 / 证据不足”（不按 0 分计）；
  - 勾选“盲评模式”后，隐藏发言者、生成方式和他人评分，顺序按评价者编码打乱；
  - 可以导入自定义量规 JSON，也可以导入导出评分。
- **评分一致性**：多位评价者评完后，查看每个维度的加权 κ、Krippendorff α 和 ICC(2,1)。
- **研究项目**：填写研究问题、研究设计、组别、时间点、伦理批准号、AI 使用声明；右侧“发表前自检”列出常见审稿关注点。
- **被试与知情同意**：只用研究编码；只有“已同意”的被试进入分析与导出；被试退出后可以删除其全部研究数据。
- **量表与测试**：
  - 量表支持维度和反向题，一键计算 Cronbach α 和描述统计；
  - 测试按答案键自动计分并做题目分析（难度、区分度、KR-20）；
  - 可以从产物库的试卷生成测试。
- **话语编码**：导入课堂或教研转录，多名编码者盲编，计算 κ / α，做滞后序列分析，并导出 ENA 格式数据。
- **数据包导出**：
  - 一键下载项目数据：被试、题项、作答（附 SPSS 语法）、分析结果、R 脚本、数据字典和 SHA-256 清单；
  - 单张表可以导出 Excel / CSV / SPSS / JSON；
  - 平台过程数据（运行、对话、调度、产物、评分）在“平台过程数据导出”。
- **边界**：平台只计算描述统计和信度，组间差异、前后测比较请在 SPSS 或 R 中完成；模拟智能体的数据不能当作真实学生的学习证据。

## 智能导入（所有表格通用）

- 支持 .xlsx、.csv、.tsv、.json。
- 表头可以用自己的叫法，系统按同义词和相似度自动对应到字段，每列标出匹配把握（精确 / 高 / 请核对），可以手动修改。
- 导入前逐行校验，有问题的行逐条列出，可以选择跳过。
- 姓名、学号、身份证号、手机号、邮箱等列会被自动忽略，也不会显示出来。
- 导入模板只有表头和字段说明，不含示例数据。

## 显示与辅助

- 右上角三个“A”分别是标准、较大、特大字号。
- 显示模式可选自动、浅色、深色。
- “?”重新查看本页的操作指引；📖 打开操作手册。
- 数字客服思思在屏幕右下角，点她即可提问；点 🔊 可以打开或关闭语音朗读，每条回答旁的 ▶ 可以单独朗读。

## 数据安全与隐私

- API Key 只保存在服务器，经过加密，不会出现在页面、日志或导出文件中。
- 上传的材料只保存提取的文字，手机号、身份证号、学号、邮箱会被自动隐去。
- 请不要上传学生名单、成绩单等含个人信息的文件。
- 研究导出默认假名化，不含自由文本，除非教师主动选择“完整研究包”。

## 常见问题

- **演课场点 ▶ 提示“暂无当前产物”**：先在研课场打开一份教案或课件，点“送到演课场上课 →”。
- **提示“模型不可用”**：管理员还没有配置模型或 API Key，请改用“模拟演示”，或联系管理员配置。
- **新建任务识别出的课程不对**：在“导入课程内容”的材料列表里只勾选这门课的材料；新上传的材料会自动取代默认勾选。
- **上课太慢**：默认已是 10×，可以选 20× 或 60×，也可以点“快进”。
- **研课场信息太多**：点“简洁视图”。
- **积分不够**：联系管理员分配；本地生成不需要积分。
- **页面打不开**：确认平台已启动，地址为 http://127.0.0.1:8787/ 。
