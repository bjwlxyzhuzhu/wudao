# 验收记录 V01—V28（2026-09-23，Claude）

证据类型分开记录：**静** = 代码静态检查/语法检查；**测** = 领域/接口自动化测试；**浏** = 真实浏览器操作（headless Chrome 经 DevTools 协议驱动实际页面，`tests/e2e/browser-shots.mjs`）；**件** = 下载文件检验；**视** = 截图人工视觉检查。

> **数量以 [../VERIFICATION.md](../VERIFICATION.md) 为准。** 本文各条记录的是当次验收时的状态，其中的测试数量是当时的规模，会随版本变化。
> `docs/screenshots/` 与 `backups/` 两个目录**不随源码包分发**，因此文中标注为「浏」「视」的证据无法从本包直接复核；需要时可自行运行 `node tests/e2e/browser-shots.mjs` 重新生成。

> 真实模型相关项均使用**本地模拟模型服务**（OpenAI 兼容与 Anthropic 两种流式格式）验证；**未使用真实供应商 API Key**，因此“真实调用”一律标为“未验收（外部条件）”，不以模拟替代。

## 未完成项与外部阻塞

1. **真实模型调用**（P1-1）：需要管理员在后台配置真实供应商的 base_url、模型ID 与 API Key。配置后先用“连接测试”确认，再用小预算运行验收 V05/V07/V08/V20 的真实版本。
2. **正式部署**：需 HTTPS、`YANZHI_MASTER_KEY` 环境变量、反向代理与备份策略；本期未授权公开部署。当前为单进程 SQLite，登录限流与步进锁在进程内存中，不支持多实例。
3. **P2 未实现**：PPTX 导出（课件目前为可编辑页面结构 + HTML 预览，DOCX 按钮对课件禁用，不把 HTML 标为 PPTX）、语音、真实学情测量、研究评分者独立账号。
4. **已知局限**：预设演示句库较小，课堂台词会重复（调度是真实随机的，台词不是）；研讨演示模式中对真人发言的回应是固定句；席位上限 12，未实现“大教研室分桌并聚焦单桌”；供应商费用未接入真实账单，后台不展示估算费用；量规未经效度验证。
